الإعدادات

أرسله في الهيدر x-api-key. التجديد يبطل المفتاح القديم فوراً.
كل طلب webhook يُوقّع بـ HMAC-SHA256 في الهيدر X-Signature: sha256=…
كيف أتحقق من التوقيع؟ (Node.js) 
const crypto = require('crypto');
const sig = req.get('X-Signature'); // "sha256=abc..."
const expected = 'sha256=' + crypto
  .createHmac('sha256', WEBHOOK_SECRET)
  .update(rawBody) // نص الـ body كما وصل
  .digest('hex');
const ok = sig === expected;
